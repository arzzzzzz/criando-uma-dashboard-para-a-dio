# criando-uma-dashboard-para-a-dio
dashboard que mostra dados de venda de assinaturas de ea play e minecraft

Criei uma dashboard de vendas da Xbox Game Pass como projeto de estudo, utilizando perguntas de negócio para analisar as vendas de assinaturas da EA Play e do Minecraft, com o Xbox Game Pass como resultado final. O foco foi organizar os dados em uma interface mais simples e agradável visualmente, utilizando recursos básicos do Excel, como cores, formas, alinhamento e organização das informações.
